# FitFind

A fitness coach discovery marketplace built
with React and JavaScript.

## The Problem
Finding a fitness coach can be difficult when
pricing, specialties, coaching styles, and
qualifications are scattered across platforms.

## The Solution
FitFind is a marketplace prototype that
brings trainer profiles, specialties, pricing,
and coaching options into one experience.

## Current Features
- 25 detailed trainer profiles
- Coach specialties and pricing
- Certifications and coaching information

## Technology
- React
- JavaScript
- Vite
- CSS
- Vercel

## Live Demo
https://fitfind-phi.vercel.app

## Development Roadmap
- Improve search and filtering
- Add saved trainers
- Add trainer comparisons
- Add automated tests
- Explore persistent data

# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
